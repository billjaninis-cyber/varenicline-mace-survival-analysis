# Varenicline vs. Bupropion Survival Analysis

R-based healthcare outcomes analysis comparing varenicline and bupropion for the risk of major adverse cardiac events (MACE).

## Methods

* Descriptive cohort characteristics
* Crude incidence rates
* Kaplan-Meier survival curves
* Log-rank testing
* Cox proportional hazards regression
* Propensity score estimation
* 1:1 nearest-neighbor matching
* Covariate balance assessment using standardized mean differences
* Post-matching survival analysis
* Proportional hazards diagnostics

## Tools

R packages used include:

* `survival`
* `survminer`
* `MatchIt`
* `tableone`
* `epiDisplay`
* `ggplot2`

## Skills Demonstrated

This project demonstrates skills in R programming, epidemiology, survival analysis, observational study design, confounding adjustment, propensity score methods, and healthcare outcomes research.

## Data Availability

The original dataset is not included in this repository due to academic and data-use restrictions. The repository is intended to demonstrate the statistical analysis workflow and programming approach.
